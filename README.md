# Процент

Русскоязычные калькуляторы вклада, накопительного счёта, кредита и планирования расходов «кредитная карта + накопительный счёт». Суммы — в рублях, ставки и условия задаются вручную. Регистрация и экспорт результатов не предусмотрены.

## Локальный запуск

Нужны Node.js **22 или новее** и npm. Проверенное окружение: Node.js 22.23.3. Версии зависимостей закреплены в `package-lock.json`.

```sh
npm ci
npm run dev -- --hostname 127.0.0.1 --port 3000
```

Откройте [локальное приложение](http://127.0.0.1:3000). Для обычного запуска с настройками Next.js достаточно `npm run dev`.

## Проверки и production-запуск

```sh
npm test
npm run typecheck
npm run build
npm start -- --hostname 127.0.0.1 --port 3000
```

`npm start` запускает уже собранное приложение; сначала нужен успешный `npm run build`. Если порт занят, остановите прежний сервер или явно выберите свободный порт, например `--port 3001`. В текущей проверочной сессии production preview находится на [127.0.0.1:3001](http://127.0.0.1:3001); этот временный адрес не является требованием приложения или публичным размещением.

При работающем сервере дополнительно проверяются шесть HTML-страниц, метаданные, robots, sitemap и локальная PNG-картинка для ссылок:

```sh
VERIFY_ORIGIN=http://127.0.0.1:3000 node scripts/verify-server-pages.mjs
```

Результаты и границы проведённой проверки: [verification](docs/superpowers/verification/2026-11-04-financial-calculator.md).

## Домен и индексация

Для локального запуска переменные окружения не нужны. В `.env.example` описана необязательная `NEXT_PUBLIC_SITE_URL`. Когда появится настоящий публичный домен, создайте `.env.local` с его HTTPS-адресом и заново выполните сборку. Эта переменная используется при сборке статических страниц.

Без допустимого публичного HTTPS-домена страницы имеют `noindex, nofollow`, robots запрещает обход, sitemap не содержит адресов, canonical и URL для Open Graph не добавляются. С корректным доменом включаются индексация, canonical, ссылки Open Graph и sitemap ровно для шести содержательных страниц. Локальные адреса, IP, HTTP, логин/пароль и нестандартный порт не принимаются. Само указание домена не публикует сайт; хостинг отдельно не настроен.

Для проверки сборки с доменом тот же HTML-скрипт принимает `VERIFY_PUBLIC_ORIGIN`, равный домену, использованному при сборке. Не задавайте его при проверке сборки без домена.

## Данные в браузере

Расчёты выполняются в браузере. Финансовые параметры не добавляются в URL, не отправляются на сервер для вычисления и не передаются сторонней аналитике. Последний корректный ввод каждого инструмента хранится в `localStorage` текущего браузера и текущего адреса сайта. Другой браузер или порт имеет отдельное хранилище.

Кнопка сброса в форме удаляет сохранённые параметры **этого** калькулятора и возвращает исходный пример. Чтобы удалить всё сохранённое, используйте сброс в каждом из четырёх инструментов либо очистите данные сайта средствами браузера. Некорректный новый ввод скрывает прежний результат, но не заменяет последний корректный сохранённый сценарий. Повреждённые и устаревшие записи игнорируются; при недоступном хранилище расчёт продолжает работать без сохранения.

## Финансовые модели

- **Вклад:** фактические дни, 365/366 дней соответствующего года; начало не включено, окончание включено. Пополнение приносит доход со следующего дня; возможны изменение ставки, ежемесячная выплата или выплата в конце срока, капитализация. Снятие и досрочное расторжение не моделируются.
- **Накопительный счёт:** начало включено, окончание исключено. Пополнения и снятия выполняются утром. База — ежедневный или минимальный месячный остаток; для неполных месяцев выбирается учёт фактических дней или исключение. Начисленный, но невыплаченный доход входит в капитал, а не в доступные деньги.
- **Кредит:** аннуитетная или дифференцированная месячная модель со ставкой `годовая / 12`; разовая и ежемесячная комиссии учитываются отдельно от процентов. Финальный платёж корректирует округление и закрывает долг. Нет досрочного погашения, страхования, просрочек, переноса выходных и регулируемой ПСК.
- **Карта + счёт:** средние траты в месяц с отдельными месячными исправлениями, равномерные дневные расходы, ежемесячное полное погашение в выбранное число и ручные промежуточные платежи. Пополнения — разовые и периодические. Даты начала и окончания включаются; неполные месяцы учитываются пропорционально дням. Итоговый капитал включает проценты и вычитает оставшийся долг, без принудительного погашения на конечную дату. Комиссии за весь горизонт списываются один раз в конце. Дефицит показывается по каждому сценарию с датой; сравнительная выгода доступна только при достаточности средств в обоих. Условия льготного периода проверяются по договору, без расчёта процентов/штрафов карты и кешбэка. Новые параметры хранятся отдельно в версии 2; прежняя карточная запись сохраняется без автоматического преобразования до явного сброса.

Вклад и накопления ограничены 10 годами, кредит — 600 месяцами (50 лет), карточный сценарий — 10 годами по выбранную конечную дату включительно. Для накоплений допустимо суммарно до 500 датированных событий; для карты — до 500 пополнений, ручных платежей и изменений ставки с учётом повторов. Автоматические дневные расходы и ежемесячные полные погашения в этот предел не входят. Суммы — до 1 трлн ₽, ставка — от 0 до 1000% годовых. Доход показан **до НДФЛ**: автоматического расчёта налога нет. Это явно описанные модели, условия конкретного банка могут отличаться. Подробности, формулы и источники доступны на странице [«Методика»](http://127.0.0.1:3000/methodology).
