# Проверка «Карта + счёт»: месячное планирование

Дата: 2026-11-04. Выполнен согласованный план `docs/superpowers/plans/2026-11-04-card-monthly-planning.md`; ручная интерактивная проверка в браузере ограничена средой, как описано ниже.

## Результат

- Вместо одной покупки — средние месячные траты, отдельные исправления календарных месяцев и равномерные расходы по дням с распределением копеек.
- Даты начала/окончания включаются. Для неполных месяцев учитываются соответствующие календарные дни. Исправления не теряются при изменении средней суммы и временном изменении горизонта.
- Полное погашение ежемесячно в выбранное число; 31-е переносится на последний день короткого месяца. Ручные платежи уменьшают оставшийся долг. Освободившийся лимит используется для последующих дней, превышение лимита оплачивается своими деньгами.
- Конечная дата даёт состояние счёта, задолженность и капитал за вычетом долга, без обязательного закрытия карты. График и помесячная таблица используют тот же капитал. Ошибки достаточности денег независимы для двух сценариев.
- Разовые и периодические пополнения сохранены. Новые карточные параметры хранятся в `procent:v2:credit-card`; старый ключ не преобразуется и не перезаписывается. Явный сброс удаляет обе карточные версии.
